About ColorDice.fr

How do these virtual dice work? / Comment fonctionnent ces dés virtuels ?
This website uses virtual dice created with an algorithm that assigns equal probabilities to every possible outcome. By clicking on the "Roll Again" button you can re-roll all the dice on this page. This page allows you to choose any number of dice between 1 and 100, each having 6 sides and 6 possible colors.
Ce site utilise des dés virtuels créés avec un algorithme qui attribue des probabilités égales à chaque résultat. En cliquant sur le bouton "Roll Again", vous pouvez relancer tous les dés. Vous pouvez choisir entre 1 et 100 dés, chacun ayant 6 faces avec 6 couleurs possibles.
